# Planet Cards

Flat pixel-art planet cards in a limited high-contrast palette, for Astroship.

Nine cards, one per body: Earth, Mars, Jupiter, Mercury, Neptune, The Moon, Saturn, Venus, Uranus. Each card is a dark navy starry field with a cream border and the planet name in bold pixel capitals.

Each planet is distinguishable by shape and features, not colour alone (craters, bands, rings), with a text label on every card — built for colourblind and vision-impaired players (PRD INTE-001).

- `planet-cards-flat-pixel-grid.png` — the full 3x3 sheet
- `planet-<name>.png` — individual cards
